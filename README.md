# APEX

A racing game for a room. One big screen hosts; phones and laptops are the controllers.

- Host: open index.html on the iPad or a computer.
- Players: open play.html, enter the 4-character room code.
- Phones steer by tilt, with brake and gas pads on each side. Laptops use WASD.

Imported images and car models go in /assets and are wired up in the ASSETS
object at the top of index.html.
